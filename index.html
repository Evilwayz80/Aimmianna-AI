Voice: picking the phone's best voice…

Settings — talk with real AI

Real AI: off — add your free Gemini key to talk with the real AI. Without it, she uses her own built-in lines.

Free key: open aistudio.google.com in your browser → Get API key → Create API key → copy it here. The key never leaves this phone except to talk to Google's AI.

Her speaking voice — Typecast (free)

Her speaking voice: Typecast not set — add your Typecast key + voice ID below to hear her AI-made voice (free, 15,000 characters a month).

How to set it up (free, no card): 1) Go to typecast.ai and make a free account. 2) Open the API Console at typecast.ai/api-console and start the free API plan — that is the plan this app uses, not a Studio subscription. 3) Copy the API key from the API Console. 4) Clone the voice from the clip you made (your emmi-voice.wav) — cloning happens in your Typecast account, not in this app. 5) Copy the voice ID: a cloned voice starts with uc_, a built-in voice starts with tc_. 6) Paste both here and tap Save voice. Her chat replies will then speak in that voice. The free API plan is 15,000 characters a month. If the app says the key is denied, generate a current key in the API Console — old Starter keys don't work with the voice API.

Her speaking voice — Fish Audio (free, backup)

Fish Audio (backup): not set — Typecast above is the free first choice.

How to set it up (free, no card): 1) Go to fish.audio and make a free account. 2) Clone the voice from the clip you made (your emmi-voice.wav) — cloning happens in your Fish Audio account, not in this app. 3) Copy the voice ID from your cloned voice. 4) Tap Get Started, then "Get your API key" — it is shown once, so copy it right away. 5) Paste both here and tap Save voice. Her chat replies will then speak in that voice if Typecast above isn't set, using the free s2.1-pro-free model ($0, no credit needed). The free offer is time-limited, so if it ever stops working this line will say so plainly and she'll just use the phone's voice instead.

Her speaking voice — ElevenLabs (backup)

ElevenLabs (backup): not set — Typecast above is the free first choice, then Fish Audio.

ElevenLabs is the third voice — Typecast above is tried first, then Fish Audio, and ElevenLabs' cloning is NOT free. How to set ElevenLabs up: 1) Make an ElevenLabs account at elevenlabs.io (cloning there is NOT free). 2) In Voice Lab, clone a voice from the clip you made (your emmi-voice.wav). 3) Copy your API key (Profile > API Keys) and the voice ID (click the voice > copy its ID). 4) Paste both here and tap Save voice. Her chat replies will then speak in that voice if Typecast and Fish Audio aren't set. If ElevenLabs ever fails — bad key, no internet, out of quota — she just uses the phone's voice instead, and this line says so.
