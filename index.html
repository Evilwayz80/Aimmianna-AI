Her speaking voice — Typecast (free)

Her speaking voice: Typecast not set — add your Typecast key + voice ID below to hear her AI-made voice (free, 15,000 characters a month).

How to set it up (free, no card): 1) Go to typecast.ai and make a free account. 2) Open the API Console at typecast.ai/api-console and start the free API plan — that is the plan this app uses, not a Studio subscription. 3) Copy the API key from the API Console. 4) Clone the voice from the voice clip you made (your greeting WAV) — cloning happens in your Typecast account, not in this app. 5) Copy the voice ID: a cloned voice starts with uc_, a built-in voice starts with tc_. 6) Paste both here and tap Save voice. Her chat replies will then speak in that voice. The free API plan is 15,000 characters a month. If the app says the key is denied, generate a current key in the API Console — old Starter keys don't work with the voice API.
